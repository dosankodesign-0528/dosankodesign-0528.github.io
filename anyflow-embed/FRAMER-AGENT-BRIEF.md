# Anyflow Embed — Framer 実装指示書

> **これは Framer の Agent に渡すための指示書です。**
> 上から順に読ませれば、1ページぶんの構造・値・アニメーション設定が揃います。
> セクション単位で切り出して渡すこともできます（`## 5` の各ブロックが独立しています）。
>
> 元の実装: `anyflow-embed/index.html`（HTML/CSS/JS 1ファイル・v61）
> 対応する Figma: セクション「最新」内の `🎬 セクションごとの動きの解説` と `🔧 Framer 実装ガイド（7つの論点）`

---

## 1. この文書の使い方

| 渡し方 | どうするか |
|---|---|
| 全部まとめて | このファイルごと Agent に渡す |
| 1セクションずつ | `## 5` の中の該当ブロックだけを渡す。**推奨はここから**（まず `5-3 実績` を試す） |
| 迷ったら | `## 7 未確認事項` を先に Agent に検証させる |

**最初に決めておくこと（これで作りが変わります）**

1. 「アニメーションが終わるまでスクロールさせない」を**再現するか / しないか**
   - **しない（推奨）** → この文書のまま進められます
   - する → `## 6-1` の Code Override が必要
2. 惑星を **動画にするか / Spline にするか**（`## 6-2`）

## 2. 前提として守ってほしいこと

- **デザインフレームは 1440 × 921（PC）／ 390 × 780（スマホ）**。この比率で組む
- **左右の余白は常に 120px**（PC）。要素は左 120px / 右 120px にアンカーする
- 出現演出の共通ルールは「**ぼけた状態から、ゆったり出る**」。単なるフェードにしない
- イージングは原則 **easeOut**。速く入って、ゆっくり収まる
- 下の `## 3` のトークン以外の値を勝手に足さない。足す必要が出たら報告する

## 5. セクション別の指示（このまま Agent に渡せます）

### 5-1. キービジュアル

```
■ 構成
- 上部にヘッダー（ロゴ / ナビ4項目 / CTAボタン「お問い合わせ」）
- 左に大見出し「AIと事業を / 強くする」（2行・SF Pro Text Weight 100・70px）
- 見出しの上に小ラベル「API でデータを繋ぐプラットフォーム」＋ 横罫線
- 右に惑星と軌道のグラフィック
- 最下部に導入企業ロゴが左へ流れ続ける帯

■ アニメーション（すべて Appear Effect ＝ ページを開いた瞬間）
1. ヘッダー：0.25秒後に Blur で出す（duration 1.5秒 / easeOut）
2. 大見出し1行目「AIと事業を」：1.0秒後から。Text Effect を per character、
   1文字あたり 0.042秒 ずらす（速く打つ印象）
3. 大見出し2行目「強くする」：1行目の 0.20秒後から。1文字あたり 0.088秒 ずらす（ゆっくり）
   → 1行目と2行目は別テキストレイヤーにして、速さを変えること
4. 小ラベル＋罫線：2行目が終わった 0.14秒後に Blur で出す
5. 惑星と軌道：小ラベルの 0.10秒後に Blur で出す（duration 1.5秒）

■ ロゴの帯
- Stack に Ticker Effect をかける
- 1周 30秒 / 方向 左 / ロゴ間の gap 96px
- ロゴは7枚を等間隔に並べる（1枚の長い画像にしないこと。継ぎ目が出る）

■ 惑星
- ここは別途 ## 6-2 を参照。動画か Spline を差し込む枠だけ用意しておく
```

### 5-2. Our Vision

```
■ 構成
- 「Our Vision」（小・26px）
- キーメッセージ2行「つなぐことが、」「強みになる時代へ。」（100px）
- 軌道グラフィック（楕円2本＋ドット6個＋中央に「Platform / プラットフォーム」）
- 右側に「連携が生む、2つの価値」＋ Point 01 / Point 02

■ 貼りつけ
- セクションを縦 1.5画面ぶんにして、中の1画面を Position: Sticky にする

■ アニメーション（Scroll Transform / Trigger: Section in view → Top）
1. 「Our Vision」を Blur で出す
2. 1行目 → 2行目の順に Blur で出す（2行目は1行目が出きる前に始めてよい）
3. 2行が上下に開いて消える
   - 1行目：Position Y  0 → −222 ／ Opacity 100% → 0%
   - 2行目：Position Y  0 → +222 ／ Opacity 100% → 0%
   - ※ 222 = 開く量92 + 慣性で流れる量130
   - Easing: easeOut
4. 軌道グラフィックが出て、拡大しながら左下へ落ちる
   - From: Scale 16% / Opacity 0% / 画面中央（2行の隙間）
   - To  : Scale 100% / Opacity 100% / 左下の着地位置
   - Easing: easeOut
   - ★ テキストと「同じ scroll section」を指定すること。開始と終了が揃う
5. 着地したら「連携が生む、2つの価値」→ Point 01 → Point 02 の順に Blur で出す
6. Point 02 と同時に、軌道上の役割ラベル（コネクタ / 認証基盤 / 権限 / ワークフロー / 監査）を出す

■ 位置の微調整（カンプからのズラし。そのまま入れること）
- 「連携が生む、2つの価値」: X −78
- Point 01: X −34
- Point 02: X 0

■ ドットの回転
- 楕円のフレームごと Rotation をかける
- ※「速く回って減速し、ちょうど1周で止まる」は Framer では再現しにくい。
  一定速度で回す形にするか、## 6-3 のコード部品にする
```

### 5-3. 実績 ★ここから試すのを推奨

```
■ 構成
- 左に縦長のグラデーション画像（941 × 1672）
- 右に見出し「事業の推進力を、/ Anyflowが支えます。」
- その下に罫線、数字4つ（導入企業 200+ / 連携実績 500+ / 稼働率 99.9% / 最短リリース 1week）
- 一番下に本文

■ 貼りつけ
- セクションを縦2画面ぶんにして、中の1画面を Position: Sticky にする

■ アニメーション
1. Trigger: Section in view → ★Center（ここだけ中央基準）
2. 見出し：Text Effect / per character / 1文字 0.055秒ずらし / Blur
3. 左の画像：Blur 24px の状態から出す
4. 数字ブロック：見出しが 55% 進んだところで出しはじめる（出きるのを待たない）
5. まわりの要素：1.6秒かけて Blur から出そろう
6. 数字はカウントアップさせない。Blur で出すだけ

■ 暗転（次のセクションへの切り替え）
1. このセクションの一番手前に、画面いっぱいのフレームを1枚重ねる
2. Fill: Linear Gradient  上 #161616 → 下 #454545
3. Scroll Transform を追加 / Trigger: Section in view（このセクション）
4. Opacity 0% → 100%
5. 効かせる範囲はスクロールの後半だけ（48%〜84% 相当）
6. Easing: easeInOut

★ 最重要 ── 次のセクションに入りきる前に Opacity 100% へ到達させること。
  半透明のまま次に入ると、2つの画面が同時に透けて見える。
  検証: プレビューでゆっくりスクロールし、黒くなりきる前に次の画面が見えないか目で追う。
```

### 5-5. 開発者体験2 — カードのカルーセル

```
■ やりたいこと
右の「CLI の場合」にマウスを乗せると、左のモック3枚が回りながら入れ替わる。

■ 組み方
1. カード3枚を「まとめて1つのコンポーネント」にする
2. バリアントを3つ作る:「API が手前」「CLI が手前」「SDK が手前」
3. 親フレームに Perspective: 1600 を設定する（★これが無いと立体に見えない）
4. 各バリアントで、3枚それぞれに下の値を設定する
5. Transition: duration 1.3秒 / easing easeOut

■ 3つの居場所の値（そのまま入力できます）

| 居場所 | Scale | X      | Y     | Z    | Rotate Y | Opacity | 重なり順 |
|--------|-------|--------|-------|------|----------|---------|---------|
| 手前   | 90.5% | 0      | 0     | 0    | 0°       | 100%    | 3       |
| 左奥   | 87.5% | −118.1 | +3.2  | −120 | +22°     | 55%     | 2       |
| 右奥   | 78.8% | +121.7 | −17.6 | −120 | −22°     | 38%     | 1       |

※ X の値は Perspective 1600 と Z −120 の組み合わせでカンプ通りの位置に着くよう
   調整済み。Perspective を変えるなら X も取り直すこと。

■ ホバー連動
- 右のテキスト3つ（API / CLI / SDK の場合）も、上のコンポーネントに含めてしまう
  → 同じコンポーネント内なので、ホバーでバリアントを切り替えられる
- 手前にあるものは白くはっきり、奥のものは薄く（Opacity を下げる）
- 手前のものだけ左に縦の線（インジケーター）を出す

■ 既知の限界
いまの実装は「動いている最中だけ回転をかけ、着いたら正面を向く」作り。
Framer の Variants は始点と終点しか指定できないので、これはそのままでは出せない。
着地時の Rotate Y を 0° にしておけば近い見え方になる。
```

## 6. コード部品（Code Component / Override）が必要な箇所

> ここは Framer の標準機能では作れません。**必要なものだけ Claude に依頼してください。**
> `.tsx` を書いて渡します。Framer に貼り付ければコード部品として使えます。

### 6-1. スクロールを止める（`## 1` で「再現する」を選んだ場合のみ）

- 種類: **Code Override**
- やること: 再生中は body のスクロールを止め、終わったら解除する
- リスク: Framer 自身の慣性スクロールと競合しやすい。実機で調整が必要
- **不要にする方法**: 「スクロールで送る」形にすれば、この部品は要りません（推奨）

### 6-2. 惑星

| 選択肢 | 内容 | 向いている場合 |
|---|---|---|
| **動画・連番画像**（推奨） | いまの実装を録画して書き出す。見た目が100%再現される | すぐ作りたい / スマホを軽くしたい |
| Spline | Spline で作り直して埋め込む | 今後スクロールやマウスに反応させたい |

> ⚠️ いまの惑星は自前の WebGL 描画なので、**Spline へのデータ変換はできません**（作り直しになります）。
> ⚠️ 動画にする場合、背景の透過が落とし穴です。地色（`#f2f2f2`）が変わらない前提なら背景ごと焼き込んで問題ありません。将来ダークにする予定があるなら連番 PNG/WebP か Spline に。

### 6-3. 軌道のドットの回転（任意）

- 種類: Code Component
- 「速く回って減速し、ちょうど1周で止まる」を再現したい場合のみ
- 妥協案: 一定速度で回し続ける（コード不要）

### 6-4. モック画面（エディタ風・チャット風）

- 種類: **Code Component**（推奨）
- 理由: いまの HTML/CSS をそのまま React にすれば見た目が100%再現される。
  Framer で手組みすると、コードの色分け（`POST` が緑、`Bearer` がピンク等）が必ずズレる
- 差し替えたい文言（見出し・チャットの文・API のパス）は Property Control として出す
  → Framer のプロパティ欄からノーコードで編集できます
