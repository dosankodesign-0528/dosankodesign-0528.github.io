## 補足

### ロゴの帯について

**必ず `logo-1` 〜 `logo-7` の7枚を等間隔（gap 96px）で並べてください。**

`logos-strip.png`（1枚につながった画像）を使うと、ループの継ぎ目に余白が生まれます。
この問題を解消するために7枚へ切り分けた経緯があるので、後戻りしないよう注意してください。

### 軌道の SVG について

軌道は **惑星を挟んで前後2枚** に分かれています。重ね順は次のとおりです。

```
手前  orbit-layer-front.svg   ← 惑星の手前を通る軌道
      惑星（WebGL のコード部品）
奥    orbit-layer-back.svg    ← 惑星の奥を通る軌道
```

この2枚構成をやめて1枚にすると、**惑星の後ろを回っているように見えなくなります**。

### 惑星について

`planet-b.png` は WebGL が使えない環境向けのフォールバック画像です。
通常は `code/` のコード部品（WebGL）が描画します。詳しくは `02-ANIMATION.md` の `## 6-5` を参照。
