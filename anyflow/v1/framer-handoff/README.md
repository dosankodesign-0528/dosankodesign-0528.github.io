# Framer 実装パッケージ — Anyflow Embed

> **いま動いている実装（v61）から、そのまま作り直せるように一式そろえたものです。**
> Framer の Agent にはこのフォルダごと渡せます。推測で埋めた値はありません。

---

## 中身

| ファイル | 中身 | いつ使うか |
|---|---|---|
| **[01-LAYOUT.md](01-LAYOUT.md)** | 全248要素の実測値（座標・サイズ・書体・色） | **画面を組むとき**。ここが図面です |
| **[02-ANIMATION.md](02-ANIMATION.md)** | 動きの指示書（秒数・発火位置・トークン・つまずきどころ） | **動きを付けるとき** |
| **[03-ASSETS.md](03-ASSETS.md)** | 画像・ロゴ・SVG の一覧と使い方 | **素材を配置するとき** |
| **[04-COPY.md](04-COPY.md)** | 全テキストの全文 | **文字を入れるとき** |
| **[assets/](assets/)** | 画像・ロゴ・SVG の実物（22点） | そのまま Framer にアップロード |
| **[code/](code/)** | Framer 用のコード部品 | 標準機能で作れない所 |

---

## 進め方（おすすめの順番）

```
1. 03-ASSETS.md を見て、assets/ の素材を Framer にアップロードする
2. 01-LAYOUT.md の座標どおりに、セクションを1つずつ組む
   → まず「02 実績」から。要素数12個で一番少なく、判断が早く付きます
3. 04-COPY.md から文字を流し込む
4. 02-ANIMATION.md を見て動きを付ける
5. code/AnyflowPlayback.tsx を貼って、スクロールの制御を入れる
```
