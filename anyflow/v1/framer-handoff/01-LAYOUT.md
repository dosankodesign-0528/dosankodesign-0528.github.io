# 01 レイアウト仕様（実測）

> **いま動いている実装から機械的に測った値です。推測は入っていません。**
> 測定条件: ビューポート 1440 × 921 / 各セクションのアニメーション完了後の状態。
> 座標は各セクションのフレーム左上が原点。単位は px。

## 座標の読み方

| 列 | 意味 |
|---|---|
| **X / Y** | フレーム左上からの位置 |
| **右から** | フレーム右端からの距離。右寄せしたい要素はこちらを使う |
| **W / H** | 実際の描画サイズ |
| **書体** | フォント / サイズ / ウェイト / 行間 / 字間 |

> ⚠️ このサイトは **高さ 921px 固定・幅は可変**（左右余白 120px）です。
> 左寄せの要素は X、右寄せの要素は「右から」を基準にしてください。
