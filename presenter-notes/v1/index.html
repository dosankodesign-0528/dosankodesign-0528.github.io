Figma と連動する鍵（client-id）

連動には Figma で無料の「OAuthアプリ」を1回だけ作り、その client-id を貼ります（全プレゼン共通）。
アプリの 「Embed API」→「Add an embed origin」 に、下のアドレスを登録してください。

編集画面の左に実際のスライド画像を出すには、Figmaの個人アクセストークンが必要です。
Figma → 右上アバター → Settings → Security → Personal access tokens → Generate new token （スコープ「File content」を Read でOK）。作ったトークンを貼ってください（このブラウザ内だけに保存されます）。
