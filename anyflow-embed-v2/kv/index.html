キービジュアル改修案（V2）

データ基盤 × AIエージェント。右がデータ基盤の網、中央のディザ発光がAIエージェント。
ドット（API）が連携先からエージェントへ流れ込み、到達するとグラデーションがふわりと反応します。
各ページ下のバーで「箱: フラット / 立体 / アイソメ」を切り替えられます。

P1 忠実・呼吸

カンプの配色そのまま。エージェントが中心から呼吸するように明滅し、ドット到達でふわりと膨らむ。
P2 ダーク・掃引

ダークテック。斜めの色帯がエージェントを掃引し、暗い盤面をドットの光が走る。
P3 波及フロー

ドットが到着した方向から、色の波がエージェントの中を押し寄せる。流入が多いほど波立つ。
P4 ミニマル線画

白ベース・細線・アウトラインの箱。エージェントはディザ粒を細かくして上品に。色相がゆっくり回る。
P5 収束ブルーム

ドットが到達すると色が中心へ吸い込まれ、ひと呼吸おいて開花するように広がる。

スタイリング違い × グラデの流れ方違いの5案。カンプ（figma 15276-23959）の座標・配色・グラデ実測値ベース。
アイコンは連携先をイメージさせる汎用ピクトグラム（データベース / ストレージ / チャット / 表計算 / 通知 / カレンダー）です。
