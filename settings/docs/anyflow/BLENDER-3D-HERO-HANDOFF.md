## 1. ゴール（何を作るか）

- Anyflow Embed の TOP キービジュアルを、**参考画像のような立体イメージ**にする。
- **参考画像の中身**：
  - 白い**フロスト（すりガラス）のアイコン**が、中央のダッシュボードを囲むように**円状に浮遊**。
  - 中央に**奥へ傾いたダッシュボード**（UIモック）が、柔らかい影を落として浮いている。
  - 地色は**薄いグレー**。全体に**スタジオ照明**のような柔らかい陰影・淡い影。
  - アイコンは**ツルツル反射のガラス玉ではなく、乳白色のフロスト**寄り。
- **今 Figma にあるのは “平面版”**（アイコンもダッシュボードも真っ平ら）。
  これを 3D パースの立体版にするのが今回の仕事。
- **最終出力**：静止画 **PNG（背景透過推奨・アルファ付き）**。サイト（`anyflow/v2`）のヒーローに使う。
  - 動かす案（Three.js / Spline）は今回はやらない。まず静止画で質感を作り切る。
- 🔴 **重要（レイヤー構成）**：線を流れる「青い光」のアニメは **Blender に焼き込まない**。
  Blender は「アイコン＋ダッシュボードの立体・質感・影」までの**静止した土台**を作る担当。
  **青い光が線を流れる動きは、その画像の“上に” SVG/CSS の別レイヤーで重ねる**（§5.5 参照）。
  光まで Blender に焼くと、あとからアニメーションできなくなる。

## 5. Blender 制作プラン（MCP でこの順に）

1. **初期化**：デフォルトの Cube / Light を整理。単位・スケールを決める（例：1アイコン = 1.0）。
2. **背景**：`Render > Film > Transparent` を ON にして **PNG アルファ**で出す（サイト側で地色に載せる）。
   影を活かしたい場合のみ、地に薄グレーのプレーンを1枚敷いて Shadow Catcher にする。
3. **アイコン（9個）**：
   - 形：**角丸の薄いキューブ**（Bevel で角丸、厚みは薄め）。サイズ均一。
   - 配置：中心を原点に**半径 R の円周**へ（§3 の中心・比率を再現）。各自の高さ(Z or 奥行き)を少し散らす。
   - マテリアル（Principled BSDF・Blender 4.x 名称）：まず**乳白フロスト**で置く
     - Base Color = 白(0.95) ／ Roughness ≈ **0.35** ／ Transmission ≈ **0.2〜0.4** ／ IOR 1.45
     - Coat（クリアコート）≈ 0.3、Subsurface を白でほんの少し → 乳白の透け感
     - ※ ツルツルの完全ガラスにしたい時は Transmission 0.9 / Roughness 0.2 に振る（仮置き→確認）
   - **記号（グリフ）**：Figma の各アイコン PNG（アルファ付き・シアン青グラデ込み）を、
     タイル前面に **画像テクスチャのデカール**として貼る（弱い Emission か Base Color）。
     ＝ SVG を押し出すより速くて確実。
4. **ダッシュボード（mock）**：`15673:27456` を **PNG 書き出し**して 1枚の板に貼る。
   奥へ傾ける（上端を奥へ X 回転 ＋ Y を少し）。エッジに薄いベベル。柔らかい影で浮遊。
5. **照明**：上・前方から**大きめ Area ライト 1灯**（キー＝柔らかい影）＋弱いフィル＋World 環境光 0.2〜0.3。
   影は**淡く柔らかく**（参考画像はコントラスト低め）。
6. **カメラ**：ほぼ正面〜**わずかに見下ろし（10〜15°）＋右へ少し回り込む** 3/4 ビュー。
   焦点距離 50〜85mm（歪み少なめ）。参考画像のアングルに合わせる。
7. **レンダー**：Cycles（質感重視／サンプル 128〜256 ＋デノイズ）。急ぐなら Eevee でも可。
   解像度は用途に合わせて（例 2880×1840 ＝ 1440×920 の 2倍）。出力 **PNG RGBA**。
   ファイル名：`kv-hero-3d.png`。

## 5.5 レイヤー構成（Blender ＋ SVG/CSS の二層）🔴

この絵は「静止の美しさ＝Blender」「動く光＝SVG/CSS」の**二層**で作るのが最適。

```
┌─ 上：SVG / CSS レイヤー（透過）… 青い光が線を流れる“動き”。軽い・iPhoneで動く
│   （既存 line1–6.svg / dot87–92.svg を活用。stroke-dashoffset か offset-path で光を走らせる）
└─ 下：Blender の静止画（PNG）… アイコン＆ダッシュボードの立体・質感・影。動かない土台
```

- **CSS で “本物の3Dライトを当て直す” はできない**（Blender出力は焼かれた平面ピクセル）。
  だが **CSS で “光の演出を上に重ねる” はできる**（ハイライトの走り／グロー／ブレンドモード／流れる光）。
- Blender 側で作るのは **接続線と光を除いた** 立体パーツ（アイコン・ダッシュボード・地の陰影）。
  - 接続線もサイト側で SVG で描くなら、Blender では線を省いてよい（＝アイコンとダッシュボードだけ）。
  - Blender で線も描きたい場合は、**光の流れだけは焼かず**、線は静的に留める。
- 「本当にマウス／光に反応させたい」なら Blender から **glTF（3Dモデル）や法線マップ**を書き出して
  **Three.js** に載せる（そこは3Dエンジンの領分・今回のスコープ外）。
